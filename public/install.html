Install Loomkey

Add it to the phone home screen from Chrome or Safari.

Chrome

Open this page in Chrome, then install. The app runs full screen and can receive push notifications in the phone shade.

Safari on iPhone

Tap Share, then Add to Home Screen. Open Loomkey from the icon, then tap Enable notifications. iPhone only delivers web push to an installed app.

Install QR

Scan with the phone camera. Accept the certificate warning once, then Chrome can install Loomkey.

Payment QR

Opens the booking payment page on the phone.
